# akita-beech-oak-sources

Survey of open spatial data on beech and oak in Akita Prefecture, for freezing on Hugging Face.
No analysis and no model are built here.

- `docs/` the written findings, one file per step
- `evidence/` the official pages, PDFs and CKAN records that the findings rest on (retrieved 2026-10-28)

Documents: `docs/01_sources_and_licences.md`, `docs/02_comparison.md`, `docs/03_final_report.md`.

Datasets built from this survey:

- 現存植生図2024: https://github.com/yuiseki/akita-vegetation-2024
- 全国森林資源メッシュ: https://github.com/yuiseki/akita-forest-resource-mesh-2026
